## Laravel Book Management Application

A Laravel-based book management application demonstrating CRUD operations, database management, searching, filtering, pagination and caching.

## Overview

This project was developed as a practical Laravel application to demonstrate my experience with PHP, Laravel, MySQL, Eloquent ORM, MVC architecture and modern web application development practices.

## Features

-Book management (Create, Read, Update and Delete)
-Search functionality
-Book filtering
-Pagination
-Form validation
-MySQL database integration
-Laravel Eloquent ORM
-Application caching
-Responsive user interface
-MVC architecture

### Technologies

-Backend: PHP, Laravel
-Database: MySQL
-Frontend: Blade, HTML, Tailwind CSS, JavaScript
-Version Control: Git / GitHub

## Installation

-Clone the repository and install the project dependencies:

composer install
npm install

-Copy the environment file and configure your database:

cp .env.example .env
php artisan key:generate

-Run the database migrations:

php artisan migrate

-Build the frontend assets:

npm run build

-Start the development server:

php artisan serve

The application will then be available locally through the Laravel development server.

## Purpose

This project forms part of my web development portfolio and demonstrates practical experience developing applications with Laravel, PHP and MySQL.
